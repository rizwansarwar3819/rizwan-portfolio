More detail

A bit more detail

Mostly hands-on — this very site is a practice project for a Web Technologies course assignment, built without a template so I could actually understand every line of the HTML, CSS and JavaScript in it.

It's a Flask-based web app built for a Computer Networks course that captures and displays live network packet information in the browser, rather than in a terminal.

Using DVWA (Damn Vulnerable Web Application) in a Docker container, I tested SQL injection, reflected XSS, command injection, and brute-force attacks at increasing difficulty levels to understand both the attack and the fix.

Before writing code for a system, sketching the sequence of interactions (like an ATM withdrawal or a login flow) helps me catch design gaps early.
